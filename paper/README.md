# Paper source

Place manuscript source files here if the repository is intended to contain the paper as well as the code artifact.

Recommended structure:

```text
paper/
  arxiv/
    arxiv.tex
    references.bib
    figures/
  neurips/
    main.tex
    references.bib
    figures/
```

Do not commit LaTeX build products (`*.aux`, `*.bbl`, `*.blg`, `*.log`, etc.). For double-blind submission, ensure the conference version is anonymized and contains no local paths, usernames, private dataset paths, or machine-specific metadata.
