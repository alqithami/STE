# Public manuscript source

`arxiv_revision/` contains the prepared replacement source for arXiv:2604.04328, including the bibliography and all referenced figures/tables. Run `latexmk -pdf main.tex` from that directory. The included `main.bbl` is intentional for the arXiv upload workflow.

The source builds a 48-page public preprint with complete proofs and separately scoped empirical appendices. It incorporates the independently inspected posterior/count comparison and excludes the defective secondary v1 mixture hard-q aggregate. Corrected v2 production results are not claimed.

Preparing and committing this source does not publish a new arXiv version. The original conference submission has not been edited. The repository landing page and docs/ARXIV_REVISION.md explain the evidence/software boundaries.
